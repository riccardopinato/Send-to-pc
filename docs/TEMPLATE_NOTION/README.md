## Regole per nuovi template

- Catalogare solo funzioni pertinenti e **native dell'app**, senza aggiungere un nuovo motore o store improprio.
- Registrare ID locale e `TPLUX-REF` master, livello E0/E1/E2/E3 e confini Product Bible; indice e JSON devono essere aggiornati insieme.
- Mai committare ZIP Notion, media, dati privati, formule di terzi, acquisti o token.
- Riuso di idee e codice originale; nessuna vendita attivata. Prezzo €3,99 resta ipotetico e richiede approvazione prima di sviluppare.
